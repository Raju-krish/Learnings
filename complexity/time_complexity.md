
Time complexity = how many operations/work the program performs.

Space complexity = how much extra memory it needs as input grows.

| Code pattern            | Complexity   |
| ----------------------- | ------------ |
| `i++`                   | O(n)         |
| `i += 2`                | O(n)         |
| `i *= 2`                | **O(log n)** |
| `i /= 2`                | **O(log n)** |
| `n = n - 1`             | O(n)         |
| `n = n / 2`             | **O(log n)** |
| Two nested `n` loops    | O(n²)        |
| `n` loop + `log n` loop | O(n log n)   |
